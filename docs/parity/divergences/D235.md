## D235 Go SDK model calls take a context.Context for Pi's options.signal

What: Pi aborts `ctx.modelRegistry.stream`, `streamSimple` and `complete` (and the same `ModelRuntime` methods) through `options.signal`, an `AbortSignal`. A Go function value cannot cross the wire in an options map, and the Go SDK's `Stream`, `StreamSimple` and `Complete` take no signal. The Go SDK adds `ModelRegistry.StreamContext`, `StreamSimpleContext` and `CompleteContext`, and the same three methods on `*sdk.ModelRuntime`. Each takes a `context.Context` first. When the context is cancelled, the SDK sends the existing `cancelModelStream` call after the `modelStream` frame on the same request lane. The host cancels the provider request, and the stream ends with the provider's aborted message (`stopReason` `"aborted"`), as a Pi provider ends a request whose signal aborted.

Not changed: the extension wire (`modelStream` and `cancelModelStream` already exist and the Node runtime uses them for `options.signal`), the RPC and JSON mode wire formats, and the existing `Stream`, `StreamSimple` and `Complete` methods.

Why: a Go extension must abort an outstanding model call when a newer request replaces it, when a session is replaced, and at shutdown, as a Pi extension does with an `AbortController`. Requested by the task owner for the AIO Go extension (`/btw`, session naming, goal review).

SCRUTINIZED:approved

Remove when: never as an API shape (Go has no AbortSignal); the record goes when the Rust, Python and Lisp SDKs expose the same cancellation and the capability moves to the cross-SDK ledger.

Call-site markers: `extensions/sdk/context.go` (`ModelRegistry.StreamContext`).

Evidence: `TestHost_Integration_SDKCompleteContextAbortsProviderRequest` (`coding/extension/host/subprocess/model_registry_cancel_test.go`): a real OpenAI-completions provider against a server that never answers; the Go SDK cancels after 100 ms, `CompleteContext` returns within 1 s with `stopReason` `"aborted"`, and the server sees its request closed. Red when the SDK does not send `cancelModelStream` (the command never returns).

Parity allowance: none needed; Pi extensions use `options.signal`, which the Node runtime already maps to `cancelModelStream`.
